**该程序代码仅供参考，具体功能请在此基础上自行修改扩展**
- 第一次下载需要在debug中设置选择擦除全部Flash下载bootloader程序
- 上位机需在连接好串口线后运行
- 红灯亮起表示准备好刷写，此时按下上位机发送文件即可自动开始升级程序，需注意第一次运行bootloader后请在红灯亮起5秒内发送文件已确保运行区有可运行程序，否则需重新刷写一遍bootloader
- 后续即可在程序运行过程中，以app程序为模板，将生成的bin文件通过上位机发送以实现程序运行中升级
- 以太网连接的ip地址可在hal_conf.h文件中进行更改
- wifi的连接直接通过at指令即可，参照app程序内esp_startup线程
